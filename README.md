# Amazon Clone

## Overview

An Amazon-inspired e-commerce web application built with modern frontend technologies.

This project is based on an open-source Amazon Clone and is being studied and developed as part of my frontend development learning.

## Technologies Used

* JavaScript
* React
* Redux
* Vite
* Material UI
* Bootstrap
* React-Bootstrap

## Features

* User authentication
* Admin dashboard
* Product listings
* Product search and filtering
* Shopping cart
* Orders management
* Responsive design
* Arabic & English internationalization

## Getting Started

### Prerequisites

Make sure you have [Node.js](https://nodejs.org/) installed.

### Installation

```bash
git clone YOUR_REPOSITORY_URL
cd Amazon-Clone
npm install
```

### Running the Application

```bash
npm start
```

This starts the development server and JSON server.

## Available Scripts

* `dev` — Starts the development server
* `build` — Builds the application for production
* `lint` — Runs ESLint
* `preview` — Previews the production build
* `server` — Starts the JSON server
* `start` — Runs both the development server and JSON server
